# Podstawy programowania – Python 🐍

Repozytorium zawiera **rozwiązania zadań laboratoryjnych**
z przedmiotu **Podstawy programowania** realizowanego w języku **Python**.

Projekt ma charakter **edukacyjny** i został przygotowany w celu nauki
podstaw programowania oraz utrwalenia zagadnień omawianych na zajęciach.

---

## 📁 Struktura repozytorium


- `basics_labs_pl/` – rozwiązania zadań laboratoryjnych  
- każdy plik `.py` odpowiada **konkretnemu laboratorium i zadaniu**
- nazwy plików ułatwiają identyfikację numeru laboratorium oraz tematu

---

## ▶️ Uruchamianie programów

### Wymagania
- Python **3.x**
- (opcjonalnie) Visual Studio Code

### Uruchamianie w Visual Studio Code
1. Otwórz repozytorium w **Visual Studio Code**
2. Przejdź do folderu `basics_labs_pl`
3. Otwórz wybrany plik `.py`
4. Kliknij **Run Python File**

### Przykładowe uruchomienie w terminalu
```bash
python lab04_zad5_rownanie_kwadratowe.py
